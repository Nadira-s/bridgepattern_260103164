# Java Proxy and Bridge Patterns

Beginner-friendly examples for the six exercises in the Proxy and Bridge patterns worksheet. The project uses plain Java and needs no external libraries.

## Requirements

- Java Development Kit (JDK) 8 or newer

## Compile and run

Open a terminal in this folder and run:

```sh
mkdir -p out
javac -d out src/*.java
java -cp out Main
```

The examples are grouped by pattern:

- `ProxyExamples.java` contains the image, video, and school internet proxies.
- `BridgeExamples.java` contains devices, remotes, and the weapon system.
- `Main.java` runs all six worksheet tasks.
